# Sito pubblico di Nexis

Vetrina statica servita da GitHub Pages: <https://demarketplace3-lab.github.io/nexis-sito/>

Nessun build, nessuna dipendenza: `index.html` + `stile.css` + immagini.
Qui non c'è il codice dell'applicazione, che resta nel repository privato.

Per aggiornarlo: `npm run sito:pubblica` dal progetto (copia i file e fa push).
